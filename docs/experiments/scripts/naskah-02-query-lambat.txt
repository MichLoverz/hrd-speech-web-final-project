Biasanya saya mulai dari mengukur dulu, bukan menebak. Saya cek slow query log dan jalankan EXPLAIN untuk melihat apakah query-nya melakukan full table scan. Kalau iya, langkah pertama biasanya menambahkan index yang tepat, misalnya composite index di kolom yang dipakai di WHERE dan ORDER BY. Kalau masalahnya ada di aplikasi, sering kali itu N plus satu query, jadi saya pakai eager loading dengan with di Laravel supaya jadi satu query saja. Untuk data yang jarang berubah, saya tambahkan caching di Redis dengan waktu kedaluwarsa sekitar lima menit. Setelah itu saya ukur lagi, karena optimasi tanpa angka sebelum dan sesudah itu cuma perasaan.
