# 2026-10-20 — Demo lewat tunnel ngrok

Besok (21 Oktober) ada sesi expert Venture Creation: presentasi 3 menit, prototype dan BMC dinilai orang luar. Presentasi sebelumnya kehilangan hampir 10 menit untuk memindahkan HDMI ke laptop.

- **Keputusan: demo lewat tunnel dari laptop, bukan deploy ke cloud.** Vercel tidak bisa menjalankan proses Python yang hidup terus dengan WebSocket dan model ~2 GB. Hugging Face Spaces gratis tidak punya disk permanen. Kredit trial GCP habis 22 Oktober, dan kecepatan Whisper di vCPU cloud belum pernah diukur — terlalu berisiko untuk dipakai malam sebelum presentasi. Deployment permanen dibahas setelah presentasi.
- **ngrok dipilih, bukan Cloudflare Quick Tunnel atau Playit.** Domain gratis ngrok tetap (bisa disiapkan sebelum presentasi, tidak berubah saat pindah jaringan), agennya lewat port 443 sehingga lebih jarang diblokir jaringan kampus. Playit hanya meneruskan TCP mentah tanpa HTTPS, padahal mikrofon di browser butuh HTTPS.
- Domain ngrok hanya satu, jadi Caddy di laptop membagi jalur: `/asr/stream` dan `/health` ke service ASR, sisanya ke Laravel. `/asr/transcribe` dan `/nlp/embed` tetap tidak terbuka dari internet.
- Alamat ASR untuk browser (`ASR_PUBLIC_HTTP_URL`) dipisah dari alamat yang dipakai Laravel sendiri (`ASR_HTTP_URL`, tetap `127.0.0.1`).
- **Bug saat uji pertama:** halaman tampil tanpa CSS. Laravel menulis URL aset dengan `http://` di halaman `https://`, dan browser memblokirnya. Penyebabnya: pengaturan proxy dibaca dari `.env` di `bootstrap/app.php`, padahal `.env` belum dimuat di titik itu, sehingga pengaturannya diam-diam tidak pernah aktif. Sekarang Laravel selalu mempercayai proxy dari `127.0.0.1`/`::1` (hanya proses lokal yang bisa menjadi proxy).
- Sesi demo satu pertanyaan: `hirenote:prototype-demo --single`.
- Diverifikasi mahasiswa dari laptop dan dari HP dengan data seluler. Perekaman live lewat tunnel belum dicoba; handshake WebSocket lewat ngrok berhasil.
- ngrok hanya untuk demo dengan data uji: data lewat server ngrok, pihak ketiga yang tidak disebut di teks persetujuan.
