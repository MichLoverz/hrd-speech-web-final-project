## Masalah yang muncul dan penyelesaiannya

- **Breeze memasang Tailwind 3 sementara Laravel 12 menyertakan plugin Tailwind 4** di `package.json`. Plugin v4 dihapus; tetap di Tailwind 3 (PostCSS) karena itu yang dikonfigurasi Breeze.
- **Laravel 12 tidak lagi menyertakan trait `AuthorizesRequests` di base Controller.** Ditambahkan manual supaya `$this->authorize()` jalan.
- **Kelas `.status-active` dkk. ter-purge Tailwind** karena hanya dirujuk dari `app/Support/helpers.php`, bukan dari Blade. Perbaikan: `./app/**/*.php` ditambahkan ke `content`.
- **Angka nol bergaris di Atkinson Hyperlegible** membuat nominal rupiah sulit dibaca. Font UI diganti IBM Plex Sans dengan `tnum`.
- **Heredoc bash di Git Bash Windows** beberapa kali gagal parse untuk konten Blade; berkas ditulis lewat editor langsung. Tidak berdampak ke kode.
- **Screenshot headless Chrome di 400 px** tidak valid — Chrome di Windows punya lebar jendela minimum ±500 px. Verifikasi responsif dilakukan di 600 px; uji di HP sungguhan masih perlu dilakukan.

## Yang dicoba tapi tidak dipakai

Diganti partial `_criterion-fields` / `_question-fields` dengan hidden `_editor` untuk menandai form mana yang dikirim.

# Sesi 2 (malam) — Fase 1 selesai

## Perubahan arah

Diskusi mahasiswa dengan dosen SR: fokus boleh bergeser melampaui ASR (mis. 40:60 SR:NLP). Konsekuensi dicatat di **ADR-004**: pipeline kartu skor menjadi komponen yang dievaluasi (retrieval embedding lokal + LLM + verifikasi kutipan), penilaian manual menjadi baseline manusia, `asr/` → `services/`. AI/LLM eksternal dikonfirmasi tidak dibatasi oleh mahasiswa.

## Yang dikerjakan

- Tabel `manual_assessments` + `manual_scores` (satu penilaian per penilai per sesi), model `ManualAssessment`/`ManualScore`, `weightedScore()`.
- Form penilaian manual di halaman sesi: skor 1–5 per kriteria + catatan; simpan draf / kirim; terkunci setelah dikirim; **blind rating** — penilaian panel lain hanya tampil setelah user mengirim miliknya (admin dikecualikan).
- Halaman perbandingan kandidat per lowongan (`/job-openings/{id}/compare`): rata-rata per kriteria, total berbobot, jumlah penilai, posisi ekspektasi gaji terhadap anggaran.
- Filter sesi: nama kandidat, lowongan, status, rentang tanggal.
- Admin: daftar pengguna + ubah peran (tidak bisa mencabut admin dari diri sendiri).
- Komponen `x-money-input` (pemisah ribuan) dari catatan uji mahasiswa.
- Dokumentasi Web Programming: `routes.md` (dari `route:list --json`), `models.md`, `request-flow.md`, `install.md`, `folder-structure.md`; ERD diperbarui.
- 40 tes lulus.

## Masalah

- Radio skor 1–5 tampil sebagai lingkaran hitam bergaris — kelas `form-checkbox` dipakai untuk `<input type=radio>`. Ditemukan lewat screenshot, dibuat kelas `field-radio`.
- Heredoc bash di Git Bash Windows menggandakan/menghilangkan backslash pada string PHP namespace; skrip patch ditulis ke berkas dulu.
- XAMPP MySQL mati di tengah sesi (kemungkinan ditutup) — `migrate` gagal 2002; dinyalakan ulang.

## Keputusan

- Penilai harus mengirim penilaian manual **sebelum** melihat penilaian lain atau (nanti) kartu skor AI — mencegah bias, diperlukan untuk metrik agreement.
- Halaman perbandingan Fase 1 hanya memakai penilaian manual yang sudah dikirim; skor AI bergabung di Fase 4.

## Berikutnya

Tag `v0.1-crud`. Lalu Fase 2: prototipe ASR di `services/` (CLI mikrofon → partial transcript + latency di terminal).
