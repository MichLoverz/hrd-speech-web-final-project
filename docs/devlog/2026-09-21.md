## Masalah yang muncul dan penyelesaiannya

- **Breeze memasang Tailwind 3 sementara Laravel 12 menyertakan plugin Tailwind 4** di `package.json`. Plugin v4 dihapus; tetap di Tailwind 3 (PostCSS) karena itu yang dikonfigurasi Breeze.
- **Laravel 12 tidak lagi menyertakan trait `AuthorizesRequests` di base Controller.** Ditambahkan manual supaya `$this->authorize()` jalan.
- **Kelas `.status-active` dkk. ter-purge Tailwind** karena hanya dirujuk dari `app/Support/helpers.php`, bukan dari Blade. Perbaikan: `./app/**/*.php` ditambahkan ke `content`.
- **Angka nol bergaris di Atkinson Hyperlegible** membuat nominal rupiah sulit dibaca. Font UI diganti IBM Plex Sans dengan `tnum`.
- **Heredoc bash di Git Bash Windows** beberapa kali gagal parse untuk konten Blade; berkas ditulis lewat editor langsung. Tidak berdampak ke kode.
- **Screenshot headless Chrome di 400 px** tidak valid — Chrome di Windows punya lebar jendela minimum ±500 px. Verifikasi responsif dilakukan di 600 px; uji di HP sungguhan masih perlu dilakukan.

## Yang dicoba tapi tidak dipakai

- `x-field` (komponen dengan `@error` otomatis) untuk form inline kriteria/pertanyaan: tidak cocok karena ada banyak form dengan nama field sama di satu halaman, error akan muncul di semua form. Diganti partial `_criterion-fields` / `_question-fields` dengan hidden `_editor` untuk menandai form mana yang dikirim.
